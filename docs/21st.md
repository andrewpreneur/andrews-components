# 21st.dev

Two things in one MCP server (`.mcp.json` → `21st`, key from env `API_KEY_21ST`, never committed):
1. **Component catalog**: thousands of React/shadcn components, themes, templates. Our plan is paid: unlimited search and code retrieval. 21st's hosted AI generation is off (build with Claude instead).
2. **Video blocks + editor**: prebuilt video elements, scenes, backgrounds, transitions, captions, overlay FX and templates in 16:9 / 9:16 / 1:1 at 30 fps, which 21st can assemble and export to MP4.

## Find and save a component
1. `search` (metadata only, free) or `get_inspiration` (reranked for our design). `search_logo` for brand SVGs (but never put other brands' logos on our ads).
2. `get_component({ id })` returns source + demo + install command. Read it before saving.
3. Save it here: `API_KEY_21ST=... npm run save:21st -- <author>/<slug> --desc "..." --tags a,b --category Data`
   → files in `src/components/21st/<slug>/`, entry in `catalog/21st.json`, then `npm run find` finds it next time.
4. Use it in a composition. Most are real-time → `clock: true`.
Bookmarks: `bookmark`, `list_bookmarks`, `create_bookmark_list`, `add_to_list` keep a curated shortlist on the 21st account.

## Video blocks
- Browse free: `video_list_blocks({ kind, size, job, language, energy })` / `video_search_blocks({ query })`.
  kinds: element, scene, background, transition, captions, overlay-fx, template. jobs: titles, product-ui, devices, code, process, data, logos, gallery, testimonials, cta, backgrounds, cursors.
- Build/export a video on 21st: `video_create_project` → `video_get_doc` → `video_apply_ops` (with `baseRev`) → `video_snapshot` to check frames → `video_export` → `video_export_status` for the MP4. Exports use plan quota.
- Our default is still to render in this repo (our rules, our motion). Use 21st blocks for inspiration, for a fast first cut, or when a block does exactly the job.

## Never
- Commit the key, paste it in docs, or put it in a URL that gets saved. Use `$API_KEY_21ST`.
- Call owner-write tools (`edit_component`, `delete_*`, `edit_profile`, `send_feedback`) without Andrew asking.
